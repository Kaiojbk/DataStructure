================================================================
一、基本概念与常用术语
================================================================

★★★ 四个"单位"级概念(选择题经典设错点,定义要背准)

   数据(Data)             信息的载体,描述客观事物属性的数、字符,以及
                          所有能输入计算机并被程序识别和处理的符号集合。

   数据元素(Data Element) 数据的基本单位,通常作为一个整体处理,
                          可由若干数据项组成。          ← "基本单位"

   数据项(Data Item)      构成数据元素的、不可分割的最小单位。
                                                       ← "最小单位"

   数据对象(Data Object)  具有相同性质的数据元素的集合,是数据的子集。

   数据结构(Data Structure) 相互之间存在一种或多种特定关系的数据元素的集合。

   ⚠ 元素 = 基本单位,项 = 最小单位,这两个词极易记反。
     层次: 数据 ⊃ 数据对象 ⊃ 数据元素 ⊃ 数据项
     例: 全校学生表 → 一名学生(元素) → 学号/姓名/年龄(数据项)

★★ 数据类型与抽象数据类型(ADT)

   数据类型  一个值的集合 + 定义在该集合上的一组操作。
             原子类型: 值不可再分(int、char)
             结构类型: 值可再分解(struct、数组)

   ADT       抽象数据组织及与之相关的操作,与具体实现无关。
             表示: <数据对象 D, 数据关系 S, 基本操作 P>
             只关心"做什么",不关心"怎么做"。
             考点: ADT 的定义与实现分离 —— 同一 ADT 可有多种实现
             (线性表这个 ADT → 顺序表 / 链表两种实现)。


================================================================
二、数据结构三要素(全章骨架,必须理清)
================================================================

★★★ 1. 逻辑结构 —— 元素之间的逻辑关系,独立于存储

        线性结构: 线性表、栈、队列、串、数组      一对一
        树形结构: 树、二叉树                      一对多
        图形结构: 图                              多对多
        集合    : 元素间无其他关系                无关系
        (树、图、集合统称非线性结构)

★★★ 2. 存储结构(物理结构) —— 逻辑结构在计算机中的映像

        顺序存储   逻辑相邻 → 物理位置相邻
                   优: 可随机存取、存储密度高
                   劣: 插删要移动大量元素; 需预分配,可能溢出或浪费

        链式存储   借指针表示逻辑关系
                   优: 插删方便、不要求连续空间、无碎片问题
                   劣: 只能顺序存取、指针域占额外空间

        索引存储   索引项 = 关键字 + 地址,组成附加索引表
                   劣: 索引表占额外空间,增删要同步维护索引表

        散列存储   由关键字直接计算出存储地址(哈希存储)

★ 3. 数据的运算 —— 施加在数据上的增删改查等操作
       运算的定义针对逻辑结构,运算的实现针对存储结构。

   ⚠ 高频易错:
     (1) 逻辑结构独立于存储结构,存储结构是逻辑结构的实现。
     (2) 同一逻辑结构可有多种存储结构(线性表 → 顺序表/链表)。
     (3) 顺序存储 ≠ 线性结构: 顺序存储同样能存非线性结构
         (完全二叉树可以用一维数组存储)。
     (4) "逻辑结构与存储无关"是指不依赖具体存储方式,
         不是两者之间没有联系。


================================================================
三、算法及其特性          ★★★ 高频,几乎每年必考
================================================================

★★★ 算法: 对特定问题求解步骤的一种描述,是指令的有限序列。

   五大特性:
     ① 有穷性 —— 执行有穷步之后结束,且每一步都在有穷时间内完成
     ② 确定性 —— 每条指令含义确切、无二义性; 相同输入必得相同输出
     ③ 可行性 —— 操作都能通过已实现的基本运算执行有限次来实现
     ④ 输入   —— 零个或多个
     ⑤ 输出   —— 一个或多个(没有输出的算法毫无意义)

   ⚠ 最高频陷阱: 算法 ≠ 程序
       程序可以不满足有穷性(操作系统、服务进程长期运行),
       算法必须满足有穷性。这是"算法与程序的区别"的标准答案。

★★ 算法的描述方法: 自然语言、流程图、伪代码(类语言)、程序设计语言。

★★ 算法的评价标准(好算法应满足):
       正确性   —— 能正确解决求解问题
       可读性   —— 便于人们理解和交流
       健壮性   —— 输入非法数据时能作出适当反应,不产生莫名其妙的结果
       高效与低存储 —— 时间复杂度低、空间复杂度低


================================================================
四、算法效率的度量 —— 时间复杂度  ★★★ 全书最高频考点
================================================================

★★★ 语句频度
     一条语句在算法中被重复执行的次数。
     算法中所有语句的频度之和 = 算法的时间复杂度 T(n)。

       例: for(i=1; i<=n; i++)
               for(j=1; j<=i; j++) x++;      // 语句频度 n(n+1)/2
           T(n) = n(n+1)/2 = O(n²)

★★★ 大 O 记号
     T(n) = O(f(n)): 存在正常数 C 和 n₀,使 n ≥ n₀ 时恒有 T(n) ≤ C·f(n)。
     即只保留最高阶项,忽略系数和低阶项。

     计算规则:
       ① 用常数 1 取代运行时间中的所有加法常数
       ② 只保留最高阶项,去掉系数      3n² + 5n + 7 → O(n²)
       ③ 嵌套循环: 各层循环次数相乘
       ④ 顺序执行的语句: 取最大者(加法规则)

     常考循环模式 —— 要能秒判:
       for(i=0; i<n; i++)                            → O(n)
       for(i=1; i<=n; i*=2)                          → O(log₂n)
       for(i=0; i<n; i++) for(j=0; j<n; j++)         → O(n²)
       for(i=1; i<=n; i++) for(j=1; j<=i; j++)       → O(n²)
       while(i<=n) i = i*3;                          → O(log₃n)
       x = n; while(x>=1) x = x/2;                   → O(log₂n)

★★★ 常见复杂度量级由小到大(必背,选择题常考排序):
       O(1) < O(log₂n) < O(n) < O(n·log₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)

★★ 三种情况: 最坏时间复杂度 / 最好时间复杂度 / 平均时间复杂度
     ⚠ 若无特殊说明,考研中的"时间复杂度"一律指最坏情况。

   ⚠ 易错点:
     (1) 复杂度是渐近的,不关心常数大小: O(2n²) 与 O(n²) 是同一量级。
     (2) 代码长短与复杂度无关,只看执行次数随 n 的增长趋势。
     (3) 两个算法的时间复杂度相同,不代表实际运行速度一样。

★★ 空间复杂度 S(n) = O(g(n)) —— 算法所需存储空间是问题规模 n 的函数

     · 只计算算法额外需要的辅助空间,不包括输入数据本身。
     · 辅助空间是常量 → O(1),称原地工作(就地算法)。
     · 递归算法要考虑递归工作栈深度: 深度为 n → 空间 O(n)。
       例: 斐波那契递归求值 —— 时间 O(2ⁿ),空间 O(n)(栈深)。

★ 时间与空间往往相互矛盾: 可以时间换空间,也可以空间换时间;
  一般来说更看重时间复杂度(时间比空间更宝贵)。

五、复习优先级速查
================================================================

   【必须拿下 ★★★】
     ① 时间复杂度计算(每年必考,复习时间投入应最多)
     ② 逻辑结构与存储结构的区分与联系
     ③ 元素是"基本单位"、项是"最小单位"
     ④ 算法五大特性(尤其有穷性)与"算法 ≠ 程序"
     ⑤ 常见复杂度量级的大小排序
     ⑥ 语句频度 → T(n) → O 的换算

   【需要理解并能应用 ★★】
     ⑦ 四种存储结构的特点与优缺点对比
     ⑧ 空间复杂度分析(递归栈深度、是否原地工作)
     ⑨ 算法设计目标四条、算法描述方法
     ⑩ 抽象数据类型 ADT 与"定义与实现分离"的思想

   【过一遍有印象 ★】
     ⑪ 数据、数据对象、数据类型的精确定义
     ⑫ 数据的运算(定义针对逻辑结构,实现针对存储结构)
